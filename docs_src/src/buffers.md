# Buffers

To assist with reading long tooltips, the mod supports review buffers. The UI buffer is always available.
When focus changes, the UI buffer is updated with the contents of the focused element.

Other screens can expose additional buffers, such as notifications on the adventure map or combat events.

- `Ctrl+Left`: previous buffer
- `Ctrl+Right`: next buffer
- `Ctrl+Up`: previous line in the current buffer
- `Ctrl+Down`: next line in the current buffer
- `Ctrl+Home`: first line in the current buffer
- `Ctrl+End`: last line in the current buffer
